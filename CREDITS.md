# Créditos

Interface e exemplos criados para esta reconstrução. Nenhum logo, foto ou texto institucional do programa original foi reutilizado.

Bibliotecas Rust: eframe/egui (MIT/Apache-2.0), serde e serde_json (MIT/Apache-2.0), image (MIT/Apache-2.0), rfd (MIT), xml-rs (MIT) e flate2 (MIT/Apache-2.0). Fontes padrão fornecidas pelo egui; PDFs usam Helvetica padrão do leitor PDF.

Regras de funcionamento observadas no código Python fornecido e reimplementadas de forma independente; detalhes e localizações em MECHANICS.md.

Referências adicionais de produto solicitadas: Gradepen (https://gradepen.com/p/) e Minha Prova (https://www.minhaprova.com.br), consultadas em 08/11/2026 para banco de questões, variações de prova, cabeçalhos e gabaritos. Sem afiliação; nenhum código, marca ou ativo visual dessas plataformas foi copiado. Consulta de releases via API pública do GitHub, usando curl do Windows.
